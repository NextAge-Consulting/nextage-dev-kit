# Exa

Ref first, Exa second. Go to Ref for any library or framework documentation; reach for Exa when Ref returns nothing useful, or when the question has a conceptual half that Ref does not cover.

Exa answers conceptual and architectural questions, general technical best practices not tied to one library, emerging patterns and industry standards, debugging approaches the docs do not cover, and comparisons of approaches or trade-offs. Standard library docs, API references, and syntax questions go to Ref.

- `mcp__exa__web_search_exa` — concepts, articles, discussions.
- `mcp__exa__get_code_context_exa` — code patterns and examples.

Set `type: "deep"` on `web_search_exa` when the human says "deep dive" or "research this". Ordinary Exa use leaves it unset.
